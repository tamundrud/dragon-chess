# Knight battle artwork provenance

The four pose sheets, bubble-free Piffleworm release pose and Hooligan pawn defender were generated for this project on 2026-10-27 using OpenAI image generation. Prompts requested original, richly painted 2D storybook fantasy characters, separate connected poses, transparent backgrounds, and no copied or screen-adaptation character designs. Follow-up generations were used to improve spacing. The final sheets are provisional and require individual owner visual acceptance. The named roles and species are from the approved roster; these images are new interpretations, not source-book illustrations.

Windwalker and One Eye's sheets contain adjacent poses whose horizontal bounds overlap. `knightAssets.ts` extracts non-overlapping rectangular regions at runtime; source PNGs remain unmodified. The attack-pose exports attempted separately retained colored halos and are not included.
